# 🧑‍🍳 Personal Chef Agent

A personal chef agent that suggests recipes based on leftover ingredients using LangChain and web search.

---

## 🚀 Features
- Suggests recipes from available ingredients
- Uses web search for real cooking instructions
- Memory support using LangGraph checkpointing
- Built with LangChain + Gemini models

---

## 🛠️ Tech Stack
- LangChain
- LangGraph
- Google Gemini API
- Python
- Tavily (search engine for AI agents)

---

## ▶️ How to Run
1. Clone the repo
```bash
git clone https://github.com/poojary-nikesh1612/personal_chef_agent.git
```
```bash
cd personal_chef_agent
```
2. Install dependencies
```bash
pip install -r requirements.txt
```
3. Add API keys in .env.example or .env
```bash
GOOGLE_API_KEY='your google api key'
TAVILY_API_KEY='your tavily api key'
```
4. Open and run the notebook
